# ANALOG_VLSI_LAB
This repo showcases miniassignments and lab report submitted done as part of ANALOG VLSI LAB.



Assignemnts submitted:-
 1. Verification of Input and Output Characteristics of an NMOS
 Transistor
 2. Verification of Input and Output Characteristics of a PMOS
 Transistor
 3. Analysis of DC, AC, and Transient Response of a CS Amplifier
 4. Analysis of DC and Transient Response of a CMOS Inverter
 5. Analysis of DC Voltage Transfer Characteristics and Truth
 Table Verification of NAND and NOR Gates
 6. Symbol Formation and Truth Table Verification for NAND,
 NOR, D Flip-Flop, and NOT Gates
 7. Implementation and Analysis of a Current Mirror Circuit.
